# Predicting poll scores

CS156 First Pipeline assignment using 260 graded poll responses from two students. The project uses MiniLM embeddings to compare logistic regression, a feedforward neural network, and the same network with dropout when predicting scores of 2, 3, or 4.

[Open the notebook in Google Colab](https://colab.research.google.com/drive/1b2ToDl047SgdoWqqLcInzZIGl9GHwl0j?usp=sharing) and run the cells in order.

- [Notebook](notebooks/predicting-poll-scores.ipynb): final code with saved results and plots.
- [Python script](predicting_poll_scores.py): the same analysis as a script.
- [Data](data/): the two poll-response datasets.
