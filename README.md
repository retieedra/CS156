# CS156 submitted workbook code

This repository collects the code submitted for the first nine sessions of **CS156: Finding Patterns in Data with Machine Learning**. Each class has numbered files under `submitted-cells/` and a code-only notebook under `notebooks/`. The numbers match the original workbook cells; omitted numbers were blank or only unfilled placeholders.

| Session | Class | Included cells |
| --- | --- | --- |
| 1 | [Introduction and Overview](classes/01-introduction-and-overview/) | 1–2 from the submitted notebook attachment |
| 2 | [Tensors, Classification, and Regression](classes/02-linear-algebra-1-tensors-classification-and-regression/) | 1–3 |
| 3 | [Collinearity](classes/03-linear-algebra-2-collinearity/) | 1–2 |
| 4 | [Decision Trees](classes/04-trees-1-classification-by-partition/) | 1–3 |
| 5 | [Naive Bayes](classes/05-max-likelihood-1-naive-bayes/) | 1–3 |
| 6 | [Maximum Likelihood Estimation](classes/06-max-likelihood-2-parameter-estimation/) | 1–4 |
| 7 | [Feed Forward Neural Networks](classes/07-networks-1-feed-forward-neural-networks/) | 1–2 |
| 8 | [Multivariate Derivatives](classes/08-gradients-multivariate-derivatives/) | 1–6 |
| 9 | [Metrics and Cross Validation](classes/09-metrics-and-cross-validation/) | 1–6 |

Only code present in the submitted workbooks or the submitted session 1 notebook attachment is included. Local preparation drafts, written responses, class datasets, and notebook outputs are excluded from the submitted-workbook collection. Submitted code is preserved even where it has an error or depends on missing context; nothing has been completed or repaired for this collection.

The [manifest](classes/manifest.json) records each session's source and omitted cell numbers. The notebooks contain the included cells in order and clear execution output. Run them with the libraries imported in their cells; individual cell files share state and may not work independently.
